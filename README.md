# FROSTLINE Arena

칼바람의 단일 공격로 전투에서 영감을 받은 학교 과제용 2D 웹게임입니다. 직접 그리는 Canvas 그래픽을 사용하며, 기존 게임의 캐릭터·이미지·음원을 사용하지 않습니다.

## 실행

Node.js 20 이상에서 다음 명령을 실행합니다. 외부 런타임 패키지나 API 키는 필요하지 않습니다.

```sh
cd /workspace/asdf
npm start
```

자기 컴퓨터에 저장소를 내려받았다면 해당 저장소 폴더에서 `npm start`를 실행하고, 브라우저 주소창에 `http://localhost:3000`을 입력하세요. HTML 파일을 직접 여는 대신 Node 서버를 실행해야 합니다. 포트는 `PORT` 환경변수로 변경할 수 있습니다.

## 컴퓨터 한 대로 테스트

1. 영웅을 고르고 **전장 만들기**를 누르면 봇과 즉시 대전합니다.
2. 게임 상단의 **테스트 탭 열기**를 누릅니다. 방 코드가 자동 입력됩니다.
3. 두 번째 탭에서 다른 영웅을 선택하고 **참가하기**를 누르면 봇을 대신해 레드 팀으로 들어갑니다.
4. 두 창을 나란히 놓고 한쪽을 조작하면 다른 쪽에서도 동일한 상태를 확인할 수 있습니다. 키보드 입력은 현재 활성 창에서만 받습니다.
5. 한쪽이 **나가기**를 누르면 남은 플레이어는 다시 봇과 대결합니다. 갑작스러운 연결 끊김은 약 20초 후 봇으로 전환됩니다.

방 코드는 동일한 서버에 접속한 사람끼리 사용할 수 있습니다. 인터넷의 친구와 플레이하려면 Node 서버를 실행할 수 있는 호스팅과 HTTPS 주소가 필요합니다. 같은 Wi-Fi에서는 서버 컴퓨터의 LAN IP와 포트 3000을 사용하고 방화벽 접근을 허용하면 됩니다. 이 저장소를 만들었다고 공개 인터넷 배포가 자동 완료되는 것은 아닙니다.

## 조작과 규칙

- **땅 우클릭**: 목적지로 이동. 기존 추적을 취소하고 이동합니다. 이동 중에도 사거리 안 적을 자동 공격하며 평타 때문에 멈추지 않습니다.
- **적 우클릭**: 대상을 추적하고 사거리 안에서 약 0.22초 준비 후 평타를 공격합니다. 기사는 근접 타격, 나머지는 추적 투사체입니다.
- **A → 좌클릭**: 이동 명령 없이 사거리 안에서 클릭 지점에 가장 가까운 적을 우선 대상으로 선택합니다. 기존 이동 목적지는 유지됩니다. 대상이 죽거나 사거리 밖이면 가까운 적을 자동 공격합니다. Esc로 선택 모드를 취소합니다.
- **좌클릭**: 적 선택 표시만 합니다. S 정지 키는 없습니다.
- **Q**: 직선 투사체, 피해 130, 쿨타임 4초.
- **W**: 최대 350 거리의 지정 지점에 반경 145 범위 공격, 피해 110, 쿨타임 8초.
- **E**: 3초간 피해 180을 흡수하는 보호막, 쿨타임 10초.
- **R**: 0.65초 동안 멈춰 시전 후 지정 지점에 반경 210 범위 공격, 피해 260, 쿨타임 30초.
- **D**: 자신의 최대 체력 30% 회복, 쿨타임 45초.
- **F**: 마우스 방향 최대 180 거리 점멸, 쿨타임 45초. 다리 밖으로 나갈 수 없습니다.
- **기지**: 초당 90 체력 회복. 사망하면 7초 후 부활합니다.
- **미니언**: 시작 2초 후 첫 웨이브, 이후 13초마다 팀별 3기 생성.
- **포탑**: 사거리 안 미니언을 우선 공격합니다. 미니언과 함께 진입하세요.
- **승리**: 상대 포탑을 파괴한 뒤 보호가 해제된 코어를 파괴하세요.

궁수·마법사·기사는 체력·이동 속도·평타 사거리·피해가 다르지만, QWER·D·F는 향후 캐릭터별 교체를 위한 공통 임시 스킬입니다. 레벨·아이템·상점·정글은 아직 없습니다. 데스크톱 마우스와 키보드 조작을 기준으로 만들었습니다.

경기에 입장하면 전체 화면 전장 안에 상단 점수·시간, 우측 방 메뉴·도움말·설정, 하단 체력·스킬 HUD가 표시됩니다. 설정에서 자신의 공격 사거리 표시를 끌 수 있습니다. 브라우저 자체 전체 화면 모드를 강제로 켜지는 않습니다. 내 캐릭터의 걷기는 입력 즉시 예측하고 서버 위치로 부드럽게 보정합니다. 상대·미니언·투사체는 보간하며 피해·점멸·쿨타임은 서버가 판정합니다. 연결이 끊기면 예측 이동도 중단합니다.


## 검증

```sh
npm test
```

Node 기본 테스트 러너로 게임 규칙과 실제 HTTP 서버의 두 클라이언트 상태 공유를 검사합니다. 통합 테스트는 포트 3199를 사용합니다.

## 구성

- `server.js`: 정적 파일, 방 생성·참가, 입력 API, SSE 상태 전송.
- `game.js`: 서버 권위 방식의 이동·공격·봇·미니언·포탑·승리 판정. 30Hz 시뮬레이션, 15Hz 상태 전송. 클라이언트는 수신 위치 사이를 매 화면 프레임 보간하며, 고정 배경은 캐시해 재사용합니다.
- `public/`: 로비, Canvas 전장, 조작과 HUD.
- `test/`: 게임 규칙 및 서버 통합 테스트.

현재 방과 경기 상태는 메모리에 저장되므로 서버를 재시작하면 사라집니다. 소규모 과제 시연용 프로토타입이며, 공개 서비스용 계정·지속 저장·대규모 접속 제한은 구현하지 않았습니다. 프록시 뒤에 배포할 경우 SSE 버퍼링을 끄고 장기 연결을 지원해야 합니다.

## 다운로드 없이 고정 링크로 플레이 (Render)

이 저장소에는 `render.yaml` 자동 배포 설정이 포함되어 있습니다.

1. https://dashboard.render.com/ 에 로그인합니다.
2. **New → Blueprint**에서 GitHub 계정을 연결하고 `donguri2025-collab/asdf` 저장소를 선택합니다.
3. `render.yaml`에 정의된 `frostline-arena` 웹 서비스를 확인한 뒤 배포합니다.
4. 서비스가 **Live** 상태가 되면 Render가 표시한 HTTPS 주소로 접속합니다. 그 주소를 친구에게 공유하면 됩니다.
5. 이후 연결된 브랜치에 수정사항을 push하면 자동으로 다시 배포됩니다. 배포가 끝난 뒤 같은 주소를 새로고침하세요. 이 작업 환경의 파일만 수정하고 push하지 않으면 사이트에는 반영되지 않습니다.

무료 서비스를 지정했습니다. 서비스 생성 화면에서 현재 요금·제한을 확인하세요. 무료 인스턴스는 비활성 상태에서 중지될 수 있어 첫 접속 시 시작을 기다릴 수 있습니다. 재배포·재시작 시 진행 중인 방은 사라지므로 새 방을 만들어야 합니다. 서버 메모리에서 방을 관리하므로 인스턴스는 하나로 유지하세요.

`/health`가 정상 응답하고, 실제 HTTPS 주소에서 방 생성·두 탭 참가·이동 공유까지 확인해야 배포 검증이 완료됩니다. 로컬 테스트 통과나 설정 파일 추가만으로 공개 배포가 완료되지는 않습니다.
